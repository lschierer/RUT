# Luke Site Navigation Structure

## URL Patterns & Routing

### Static Content
- `/~luke/*.{html,txt,pdf}` → Serve directly from `packages/luke/`
- `/~luke/assets/*` → Serve from `packages/luke/staticAssets/`
- `/~luke/*.css` → Serve from `packages/luke/dist/styles/`
- `/~luke/*.js` → Serve from `packages/luke/dist/`

### Markdown Content
- `/~luke/**/*.md` → Render with template, extract YAML frontmatter
- `/~luke/**/` → Look for `index.{md,html,txt,pdf}` in directory

### Archive/Calendar Navigation

#### Year Index
**URL:** `/~luke/log/archive/{YYYY}/`

**Template:** `rut/archive/yearIndex`

**Data:**
```perl
{
  year => $year,
  months => {
    '01' => 5,  # 5 posts in January
    '03' => 12, # 12 posts in March
    # ... months with content
  },
  current_year => DateTime->now->year,
  current_month => DateTime->now->month,
}
```

**Logic:**
- Scan `log/{YYYY}/` for month directories (01-12)
- Count `.md` files in each month directory
- Only include months with content

#### Month Index
**URL:** `/~luke/log/archive/{YYYY}/{MM}/`

**Template:** `rut/archive/monthIndex`

**Data:**
```perl
{
  year => $year,
  month => $month,
  month_name => 'February',  # DateTime->month_name
  calendar_content => '<table>...</table>',  # Pre-generated HTML
  current_year => DateTime->now->year,
  current_month => DateTime->now->month,
}
```

**Calendar Fragment:**
- Pre-generated at build time: `log/archive/{YYYY}/{MM}/calendar.html`
- HTML table showing days with posts as links
- Days without posts shown as plain text

### Current Month Calendar Widget
**Helper:** `getCurrentCalendar()`

**Returns:** HTML fragment from `log/archive/{current_year}/{current_month}/calendar.html`

**Usage:** Sidebar widget showing current month's posts

## Redirects

### Hard-coded Legacy Redirects
```perl
{
  'log/20050208/20050208-1101/' => '/~luke/log/science/prolife_science/',
  'log/20050603/20050603-1424/' => '/~luke/log/Society/homosexuality/',
  'log/20050607/20050607-1002'  => '/~luke/log/Society/usury/',
  'log/20050608/20050608-1129'  => '/~luke/log/Politics_And_Law/Public_Schooling/',
  'log/20050610/20050610-1530'  => '/~luke/log/Politics_And_Law/Our_Government_Is_Unlimited',
  'log/20050610/20050610-1628'  => '/~luke/log/science/Trust/',
  'log/20050615/20050615-1338'  => '/~luke/log/Politics_And_Law/Public_Schooling/',
}
```

### Date-based URL Redirects (301)
**Pattern:** `/~luke/log/{YYYYMMDD}/{rest}`

**Logic:**
1. Check if path exists as-is
2. If not, try `/~luke/log/{YYYY}/{MM}/{DD}/{rest}`
3. If that exists, 301 redirect
4. Ensure trailing slash

**Example:**
- `/~luke/log/20070809/name-confusion` 
- → `/~luke/log/2007/08/09/name-confusion/`

### Ikiwiki Meta Redirects (308)
**Source:** `dist/redirects.json` (generated by `build_luke.pl`)

**Format:**
```json
{
  "/~luke/log/some/path/": "/~luke/log/target/path/",
  "/~luke/log/old/": "https://external.site/new/"
}
```

**Logic:**
- 308 Permanent Redirect (preserves POST method)
- Extracted from `[[!meta redir="target"]]` in `.mdwn` files

## Markdown Rendering

### YAML Frontmatter
```yaml
---
title: "Page Title"
layout: "rut"  # or "default"
date: "2007-08-09"
tags: ["tag1", "tag2"]
---
```

### Template Selection
- Default layout: `default`
- Override with `layout:` in frontmatter
- Blog posts typically use `rut` layout

### Template Variables
```perl
{
  content => $html,           # Rendered markdown
  title => $title,            # From frontmatter or path
  yaml_data => $yaml_data,    # Full frontmatter hash
  current_year => $year,      # For calendar widget
  current_month => $month,    # For calendar widget
}
```

## Category/Tag Indexes

**Pattern:** `/~luke/log/{category}/`

**Examples:**
- `/~luke/log/science/`
- `/~luke/log/Politics_And_Law/`
- `/~luke/log/Society/`

**Implementation:** Each category has an `index.md` that lists posts

## Build-time Generated Files

### Calendar Fragments
**Location:** `log/archive/{YYYY}/{MM}/calendar.html`

**Generation:** Build script scans `log/{YYYY}/{MM}/` for `.md` files

**Format:** HTML table with:
- Days with posts → links to `/~luke/log/{YYYY}/{MM}/{DD}/`
- Days without posts → plain text
- Empty cells for days outside month

### Date Manifest
**Location:** `dist/dates.json`

**Format:**
```json
{
  "log/2007/08/09/post-name.md": {
    "last_edited": "2024-01-15T10:30:00Z",
    "source": "git"  // or "frontmatter" or "meta"
  }
}
```

**Usage:** Display "Last edited: 3 days ago" on blog posts

### Redirect Manifest
**Location:** `dist/redirects.json`

**Format:**
```json
{
  "/~luke/log/old/path/": "/~luke/log/new/path/"
}
```

**Usage:** 308 redirects for ikiwiki `[[!meta redir]]` directives

## Template Hierarchy

```
templates/
├── layouts/
│   ├── default.html.ep    # Basic page layout
│   └── rut.html.ep        # Blog post layout with calendar
└── Schierer/Luke/
    ├── default.html.ep    # Markdown content wrapper
    └── rut/
        └── archive/
            ├── yearIndex.html.ep   # Year archive listing
            └── monthIndex.html.ep  # Month archive with calendar
```

## Priority Order for File Resolution

1. Check for exact match: `{path}.html`
2. Check for markdown: `{path}.md`
3. Check for PDF: `{path}.pdf`
4. Check for text: `{path}.txt`
5. Check for directory with index: `{path}/index.{html,md,pdf,txt}`
6. Return 404
